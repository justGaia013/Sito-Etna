# L’Etna – Mount Etna 🌋

Sito web bilingue (italiano / inglese) sull’Etna: informazioni generali, storia del vulcano e tipo di vulcano.
Sfondo con tramonto, silhouette dell’Etna e meteore rosse animate.

*Bilingual (Italian / English) website about Mount Etna: general info, history and type of volcano.*

## File

- `index.html` – il sito (HTML, CSS e JavaScript in un unico file)
- `404.html` – pagina di errore
- `README.md` – questa descrizione

## Pubblicare su GitHub Pages

1. Crea un repository su GitHub (es. `etna`), pubblico.
2. Carica `index.html`, `404.html` e `README.md` nella radice del repository.
3. Vai su **Settings → Pages**.
4. In **Build and deployment** scegli **Deploy from a branch**, branch **main**, cartella **/ (root)**, poi **Save**.
5. Dopo uno o due minuti il sito sarà online su `https://TUO-NOME-UTENTE.github.io/etna/`.
